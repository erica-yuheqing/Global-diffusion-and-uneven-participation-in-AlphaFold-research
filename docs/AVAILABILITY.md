# Data and code availability

**Data availability.** Processed bibliographic data, AlphaFold-use decisions, institutional group assignments, analysis inputs and figure source data are available in the [versioned Zenodo deposit](https://doi.org/10.5281/zenodo.24369846). The authors’ original data are licensed under CC BY 4.0. [Third-party terms](../THIRD_PARTY.md) apply to their respective materials. The deposit includes source identifiers and checksum inventories. The repository documents the acquisition of OpenAlex records and the reconstruction of historical journal rankings from separately obtained SCImago annual exports. The distribution excludes the original JSONL downloads, article text and private adjudication workbooks.

**Code availability.** Acquisition, processing, analysis and figure-production code is available in [the public GitHub repository](https://github.com/erica-yuheqing/Global-diffusion-and-uneven-participation-in-AlphaFold-research) under the [MIT license](../LICENSE). The [19 November analytical release with historical-code annotations](https://github.com/erica-yuheqing/Global-diffusion-and-uneven-participation-in-AlphaFold-research/tree/0741f93c1764d35a36e4ae0bac561e970cfe838c) is preserved. The [current reviewer guide](../README.md) provides the tested software versions, installation instructions, both demos and timings. [Reproduction scope](REPRODUCTION.md) and [verification records](../verification/README.md) describe which analyses were rerun.
